# Sistema de cadastro e bonificação de novos colaboradores alteração

## Descrição

Sistema responsavel pelo pelo cadastro de novos colaboradores. No sistema, deverá ser informado o nome do colaborador e seu respectivo salário. O sistema deverá retornar uma mensagem de boas vindas dizendo ao colaborador o seu salário base juntando com o seu salário bonificado com 15%

## Objetivo

Vamos fazer o calculo dando 15% de bônus no salário dos novos funcionarios.
